# Official TCS Global Associate HR Policy Repository

This repository houses the authoritative, comprehensive enterprise HR policy documents for Tata Consultancy Services (TCS). Every policy has been compiled into a dedicated, standard dense official document featuring substantive articles, eligibility matrices, procedural workflows, financial limits, and compliance escalation standards aligned with the Tata Code of Conduct (TCoC).
