# HR Policy Resources

This directory contains the official enterprise HR policy documents in PDF format for the Nexus HR Platform and Knowledge Hub.

## Available Documents

| Document | Category | Key Topics & Citations |
| :--- | :--- | :--- |
| `employee_handbook.pdf` | General Standards | Code of Conduct, Anti-Harassment, Working Hours, Remote Work Abroad (up to 20 days/year), $1,200 Learning Stipend, Ethics Hotline |
| `leave_policy.pdf` | Leave & Time Off | 20 days Annual PTO (1.67/mo), 5 days carryover to Q1 (March 31), 10 Paid Sick Days (Doctor note required for >3 days), 16 weeks Parental Leave |
| `benefits_guide.pdf` | Benefits & Wellness | Medical (PPO vs HDHP), Dental/Vision, 100% 401(k) Match up to 4%, HSA ($750/$1500), EAP Counseling (8 free sessions), $75/mo Wellness Stipend |
| `remote_work_policy.pdf` | Workplace & IT | Hybrid Cadence (3 days remote / 2 days office, mandatory Tue/Thu), $500 Home Office Stipend, $50/mo Internet Stipend, VPN Security |
| `travel_expense_policy.pdf` | Payroll & Expense | Domestic/International Approvals, Navan Platform, $200/$320 Nightly Hotel Limits, $75 Meal Per Diem, 30-Day Expense Submission Window |
| `expense_policy.pdf` | Payroll & Tax | Corporate spending standards, $100/person client dining cap, non-reimbursable expenses, 10-day credit card reconciliation |
| `travel_policy.pdf` | Workplace & IT | Duty of care, travel authorizations, economy class requirements, traveler emergency support |
| `security_policy.pdf` | Workplace & IT | 14+ character password rotation, mandatory MFA (hardware/authenticator app, SMS prohibited), clean desk, USB ban, phishing protocol |
| `performance_and_growth_policy.pdf` | General Standards | Biannual reviews (June/Dec), Feb 1 merit adjustments, Performance Improvement Plan (PIP) 30/60/90-day framework |

## Synchronization
These documents are synchronized across:
- `resources/` (Repository root document archive)
- `rag_application-main/knowledge_base/` (RAG vector ingestion target)
- `employee_frontend-main/public/policies/` (Employee Portal downloadable assets)
- `hr/frontend/public/policies/` (HR Specialist Portal downloadable assets)
