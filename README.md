# HR AI Service Desk POC

An autonomous, deep frosted spatial UI web ecosystem for modern HR operations and triage, built with **React 19 + TypeScript + Vite + Tailwind CSS**.

## Project Highlights
- **Spatial Glassmorphism UI**: Dark Obsidian (`#060814`) and Crystalline Frosted Light mode with ambient radial glows, specular borders, and neon telemetry accents.
- **Fixed Stationary Sidebar**: Layout locked to viewport with independent smooth scrolling across all component pages.
- **Operations & Navigation**:
  - **HR Dashboard**: Key metrics, glowing velocity SVG chart with dynamic 7D/30D/90D ranges, urgent case queue, real-time AI operations telemetry, and process insights.
  - **Service Requests**: Full search, category, and priority filtering.
  - **Autonomous AI Triage**: Real-time classification stream, model reasoning, human overrides, and an interactive **Classifier Sandbox Simulator**.
  - **HR Copilot**: Conversational AI assistant grounded in enterprise policies and handbooks with verified citation links.
  - **Deliverables Queue**: Official employee letters, compensation addendums, and VOE documents with 1-click approve & dispatch.
  - **Operational HR Actions**: 1-click execution for salary adjustments, sabbatical waivers, and role transitions.
  - **Backend API Docs**: In-app interactive specification explorer for all endpoints and JSON schemas.
- **Backend Blueprint**: Complete architectural documentation and endpoint specifications in [`hr/BACKEND_INTEGRATION.md`](hr/BACKEND_INTEGRATION.md).

## Quick Start (Frontend)

```bash
cd hr/frontend
npm install
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) to view the application.
